## Inherited scaffold

The following foundations derive substantially from the upstream template:

- FastAPI and React full-stack project structure
- User authentication and account management
- SQLModel and PostgreSQL integration
- Base Docker Compose and Traefik setup
- Generated OpenAPI frontend client workflow
- Initial testing and GitHub Actions structure
- Base UI component system

## TechDoc AI project-specific implementation

The following capabilities were implemented for TechDoc AI:

- Technical-document upload and lifecycle management
- TXT, Markdown, and PDF parsing
- Document splitting and chunk persistence
- BGE-M3 embedding integration
- PostgreSQL and pgvector retrieval
- Redis and Dramatiq document-processing queue
- RAG chat sessions with answer citations
- Owner-scoped document and conversation access
- Request and upload rate limiting
- Audit events and administrator audit APIs
- Prometheus metrics and Sentry integration
- RAG evaluation fixtures and metrics
- Document-library and cited-chat frontend workflows

## Generated code

Some files are generated and are not represented as hand-written project code:

- `frontend/src/client/` is generated from the OpenAPI schema
- `frontend/src/routeTree.gen.ts` is generated by TanStack Router
- Alembic migration files may contain generated migration scaffolding
